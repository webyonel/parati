# Una chica muy especial

Página estática para Glendy. Abre `index.html` en el navegador.

## Fotografías

Las imágenes están en `img/` y sus rutas se asignan en `index.html` mediante `data-photo`. Para cambiar una, edita esa ruta. La portada tiene prioridad; las demás fotos se descargan al entrar en su paso y se anticipa únicamente el paso siguiente.
